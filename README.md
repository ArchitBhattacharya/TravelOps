# Travel Rescue

> Your trip can break. Your plan doesn't have to.

Travel Rescue is an autonomous AI browser agent that helps users recover from disrupted travel situations such as cancelled flights, missed trains, delays, overbooking, and sudden price changes.

## Features

- Find alternative flights, trains, and buses
- Compare complete journeys
- Respect user constraints such as budget and deadline
- Deadline-aware route planning
- Automatic re-planning when situations change
- Emergency hotel search
- Last-mile transport planning
- Refund and compensation assistance
